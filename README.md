# AIラジオ大学

自分専用の「ラジオで聴く大学」。外部サービス・APIは一切使わず、ブラウザだけで動きます。

## 使い方
- **キャンパス**：チューニングダイヤルで学部を選び、▶でラジオ放送開始（曲紹介アナウンス付き・自動で次の講義へ）
- **ドライブモード**：車アイコン。巨大ボタン・画面点灯維持・左スワイプで次へ。車のハンドルボタンやロック画面からも操作可
- **研究室**：MP3を追加（ファイル名 `学部_タイトル_第1回.mp3` で自動振り分け）／台本から音声合成講義をつくる／Muse用の依頼文メーカー
- **学籍簿**：単位・学位・連続記録・実績・ひらめきノート

## 置き場所（無料）
フォルダ一式を GitHub Pages などの静的ホスティングに置くと、スマホで「ホーム画面に追加」してアプリとして使えます（オフライン対応）。
ローカル確認：`python3 -m http.server` → http://localhost:8000

データ（MP3含む）は各端末のブラウザ内（IndexedDB）に保存されます。

## 講義の音声化（無料・Irodori-TTS）
`tools/irodori_voice.ipynb` をGoogle Colabで開き、①〜④を順に実行すると、Googleドライブの制作ボードで「音声化待ち」の講義をMP3にします。
